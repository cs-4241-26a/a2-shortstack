## Assignment Tracker
I built an Assignment Tracker where you can input any assignment you need to complete along with its category and due date. There is also a Priority Level for major assignments that changes based on how close it is to the deadline. Users also have the ability to edit and/or delete any existing data they have submitted. In order to modify data you must click the edit button and type in your changes into the form and hit submit. I used a CSS flexbox for the layout of the form and list.

## Technical Achievements
- **Tech Achievement 1**: I created a single-page app that provides a form for users to submit data which is sent to the server and displayed on the same page for the user to see.
- **Tech Achievement 2**: I added the ability to modify any existing data from the client side which is updated to the server. Existing data can be modified/updated using the edit button. Once the edit button is clicked you can add your changes to the existing form inputs and hit submit and you will see the updates.

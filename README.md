Assignment 2 - Short Stack: Basic Two-tier Web Application using HTML/CSS/JS and Node.js  
===

## a2-RyanCarignan
### Usage
This web application is used to track vehicles for a used car salesman. Vehicles can be added via the form at the top of the page. Added vehicles can be edited by clicking on the vehicle listing at the bottom of the page, and deleted by clicking on the delete button on each vehicle listing. The application tracks the estimated value of each vehicle based on the given year and MPG.
### Design
Below are some details about the implementation the assignment directions implied should be listed. Flexbox was used to format the page. [css-gradient.com](css-gradient.com) was used to find a gradient background design. Verdana was used for the font-family. A list rather than a table was used as the structure of the list of vehicles.

## Technical Achievements
- **Single-Page App**: All of the application's functionality is accessable from a single page, as is all the information it displays to the user. The page is updated based on server responses and user actions as needed.
- **Modify Data**: Vehicle listings can be modified, in addition to being added or deleted. This is done by clicking on the vehicle listing, editing information, and then submitting the form. Vehicles are tracked by a hidden `id` value and are modified on the server-side.

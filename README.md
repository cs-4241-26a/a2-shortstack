## Score Tracker
This application allows users to track scores across sessions of a game. I was thinking of games of Warhammer 40k when designing it, but it can be used for any 2-player (or 2-team) game with numerical scores. It uses a CSS grid to style the input form, with the labels in one column and the inputs in another. It also uses JS to manipulate the CSS styling of the modify button and modifying instruction text by changing their classes.

### Technical Achievements
- **Single-Page App**: When the user submits the form, the table is automatically updated with the new game. The table does not appear until the first game is submitted.

- **Modifying Feature**: The pencil icon in each row allows the user to edit the correpsonding game. When it is pressed, that cell becomes highlighted and instructions to modify the game appear below the table. If the modify button is pressed again, the modifying feature turns off and allows new games to be submitted. If a different modify button is pressed, that game will be modified instead when the form is submitted.

### Design/Evaluation Achievements
- **User Feedback**: I worked with Nick Houghton to get feedback on my website. He had no major problems with the site, but reccomended that I swap the field order to Name-Score-Name-Score instead of Name-Name-Score-Score and that I move the instructions for modifying a game to be below the table instead of above it. He also reccomended that I add some kind of pop-up confirmation for when a game is modified or deleted. I was somewhat surprised by the reccomendation to switch the field order, as I think it is more logical to put both names first and then both scores. Based on his feedback, I would move the instructions for modifying to the bottom of the table and add a browser alert. I could also re-arrange the input fields to be a 2x2 grid instead of all in a row to improve the intuition.

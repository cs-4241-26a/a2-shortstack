## Eat the Apple - Snake Game
Play a classic game of snake with the keyboard's arrow keys. Users can enter their scores, leave comments, and view the leaderboard. Yes, you can just cheat your score entry but that would not be fun...

The elements are positioned using flexbox.
Server: Tracks user input from the form.
Results: The data is shown in a scoreboard and a data table.
Forms: The form requires the player's name, score, and a comment. Allows players to edit and delete their entry.
Server Logic: Adds time and date of a user's entry.
Derived Field: Ranks player's score based on how well they did in the game.

Render Link: https://a2-ellabrown.onrender.com

## Technical Achievements
- **Technical Achievement 1**: The application is one page. Once the user enters data, the page is updated and displays the new entry.
- **Technical Achievement 2**: Player's can edit and delete their entries from the server.

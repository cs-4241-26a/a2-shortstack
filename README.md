## Game Tracker
This project is a database of games people have played. It allows users to input a title, genre, hours played, and rating. Taking the rating information, the website provides whether or not it recommends the game. I used the 'left' CSS positioning technique with the library text. To the right of each entry are two buttons; edit and delete (denoted by the pencil and trashcan respectively). The trashcan simply deletes an entry. The edit button temporarily clears the entry and lets you re-type all information using the input fields, saving any changes and updating the recommendation if applicable.

## Technical Achievements
- **Tech Achievement 1**: Created a single-page app. Users can submit to the form, and all data (both user-inputted and derived) is displayed and updated live in the library.

- **Tech Achievement 1**: Gave the user the ability to delete and edit entries in the library. (Note: do not press the edit button then refresh the page. The row will remain empty and must be deleted).

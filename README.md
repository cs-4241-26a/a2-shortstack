Assignment 2 - Short Stack: Basic Two-tier Web Application using HTML/CSS/JS and Node.js  
===

## Patrick's Used Cars
This is the only website you will need to determine the value of your used car! I used display: flex to align my main content at the top center of the page, as well as used id and class tags for more precise and specific instances of certain tags.

## Technical Achievements
- **Tech Achievement 1**: Using JS, I was able to print out the contents of the appdata to the user and have it change in live time when updated with new data or data deletions

### Design/Evaluation Achievements
- **Design Achievement 1**: Recieved the following feedback from classmates
    - ***Hanlon, Joey***: He thought that the objective of the website was intuitive, but the formatting of the listed data was cluttered and confusing. My solution to this would be coloring the key values such as "Our Price" in a different, bolder color (which I implemented) and giving each item ample space to better align the items like a table.
    - ***Schieffer, Will***: He understood the tasks set before him, and gave advice on how in the future I could make the website more interactive and fun for the user, such as having a running balance for the money the user has which they can spend on cars and auto parts. These purchases could act as the delete function, removing them from the listed used cars on the website.


## a2-sylviacj


This is a simple task manager, lets you add, delete, and edit tasks. A grid display was used for the mostpart but the editor uses flex for when it is shown. I believe the application is self explanatory, but basically you use the right side to add tasks and can edit or delete them from the table. As something is added or deleted it the table is updated automatically all on a single page

render site: https://a2-sylviacj.onrender.com
## Technical Achievements
- **Tech Achievement 1 Single Page App**: the app does use a single page, the data submission is on the right and the table is always updated and then displayed automatically

- **Tech Achievement 1 Editing Data**: There is an edit button in front of the delete button on the table that allows for modification of tasks
